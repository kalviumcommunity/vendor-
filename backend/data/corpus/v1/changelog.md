# NovaAPI v1.0 Changelog & Release Notes

Document Type: changelog
Version: v1.0
Status: legacy
Release Date: January 15, 2023

## Release v1.0.0 (Initial Launch)
- **New**: Launch of NovaAPI v1.0 core service.
- **New**: Basic Auth credential verification.
- **New**: User management endpoints (`/user/create`, `/user/profile`).
- **New**: Dual JSON and XML payload parsing.
- **Changed**: Default rate limit initialized to 60 requests/minute per IP address.
